# Monitoramento

O sistema será monitorado em relação a dois fins:

- Métricas de requisitos
- Sustentação

## Métricas de requisitos

As métricas definidas pelos Documentos de requisitos de produto devem ser monitoradas a fim de responder as hipóteses criadas para cada requisito.

## Sustentação

São métricas relacionadas a operação do sistema, como performance, disponibilidade, preço dos serviços de forma a ter uma visão clara da capacidade de sustentação do próprio sistema.
