# RF 01.01 - Registro

__Descrição__

Como visitante quero poder me registrar para ter acesso as funcionalidades de jogadores.

Informações necessárias para o registro:

- Nome
	- Texto
	- Validadores
		- Tamanho mínimo de 6 caracteres

- Email
	- Identificador
	- Texto
	- Validadores
		- Email deve ser válido

- Senha
	- Texto
	- Deve ser criptografado
	- Validadores
		- Senha mínima de 8 caracteres

Preenchidos automaticamente

- Data de entrada: quando o cadastro foi feito


__Impacto__

Permite ao visitante se autenticar como jogador e ter acesso a várias outras funcionalidades do portal.

#### Critérios de aceite

- __CA 1: Registro com sucesso__
	- **Dado** que o visitante está na página de registro
	- **E** insere um nome com pelo menos 6 caracteres
	- **E** insere um e-mail válido e não cadastrado
	- **E** insere uma senha com pelo menos 8 caracteres
	- **Quando** clica no botão de registrar
	- **Então** o sistema deve criar a conta do jogador
	- **E** redirecionar para a página personalizada do jogador

- __CA 2: Registro com e-mail já existente__
	- **Dado** que o visitante está na página de registro
	- **Quando** insere um e-mail que já possui cadastro no sistema
	- **Então** o sistema deve exibir uma mensagem informando que o e-mail já está em uso
	- **E** oferecer um link para a página de login

- __CA 3: Validação de campos obrigatórios e formatos__
	- **Dado** que o visitante está na página de registro
	- **Quando** tenta submeter o formulário com campos vazios ou formatos inválidos (nome < 6 chars, e-mail inválido, senha < 8 chars)
	- **Então** o sistema deve exibir mensagens de erro específicas para cada campo inválido
	- **E** impedir o envio dos dados
